# 500 Days of Software

A repo for tracking the progress of me and my friends in the 500 Days of Software challenge.

The rule is simple: every day, learn or build something in software, and write down what you did. Small steps every day are better than big steps once a month.

## What You Write

Each person has one file. In your file, write what you learned and what you built each day. Keep it short and honest. Write what you really did, not what you plan to do.

Good entries say what you learned and what you did with it:
- Learned how cross validation works
- Ran code to compare two models and changed the threshold
- Solved two binary search problems

## How to Join

1. Clone this repo
2. Create a file with your name, for example `yourname.md`
3. Copy the template below into your file
4. Push your file

## Entry Template

Use one heading for each week and one line for each day. Add new days at the bottom of your file.

```
#### Your Name - 500 Days of Software

#### Week 1

`1.Sunday Oct 4, 2026 :`
- Learned ...
- Ran code for ...
```

## Daily Routine

Run these commands in the repo folder every day:

```
git pull
git add yourname.md
git commit -m "Day N update"
git push
```

Always run `git pull` first. This gets the new files from your friends and stops push errors.

## Rules

- Only edit your own file
- Push every day, even if the day was small
- If you miss a day, add it the next day. Do not delete the day
- Be kind. Cheer for your friends. Do not compare your progress with theirs
